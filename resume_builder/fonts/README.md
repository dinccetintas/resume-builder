# Bundled fonts (SIL Open Font License 1.1)

Embedded into executive-theme PDFs so Turkish and other Latin-extended
characters (İ ı ş Ş ğ Ğ ç Ç ö ü) render correctly on any machine.

| Font    | Role in the PDF        | Metric-compatible with | License file |
|---------|------------------------|------------------------|--------------|
| Caladea | name, headings, figures | Cambria               | LICENSE-Caladea-OFL.txt |
| Carlito | body text              | Calibri                | LICENSE-Carlito-OFL.txt |

The DOCX uses Cambria + Calibri, so the Word file and the PDF share
the same metrics and line breaks.
